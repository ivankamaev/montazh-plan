# Монтажный план

Веб-приложение для техдирекции и подрядчиков: таймлайн монтажа и демонтажа мероприятия (Гант по локациям, список по дням, заезды машин). Данные берутся живьём из Google-таблицы через скрипт-мост на Google Apps Script и обновляются каждые 15 секунд.

- `src/template.html` — исходник приложения (один HTML-файл). **Код правится здесь.**
- `tools/build.py` — сборка: `python3 tools/build.py --web` → `site/index.html`.
- `.github/workflows/pages.yml` — при пуше в `main` собирает и выкладывает сайт на GitHub Pages.
- `gas/` — скрипт-мост для Google Apps Script (`Code.gs`, `appsscript.json`).
- `excel/macro-list.vba` — макрос множественного выбора для старой Excel-версии таблицы.
- `CLAUDE.md` — подробное описание устройства приложения и договорённостей.
