# Монтажный план — веб-приложение

Таймлайн монтажа/демонтажа мероприятий для техдиректора и подрядчиков. Открывается с телефона по ссылке, данные — из онлайн-таблицы на Google Диске (через скрипт-мост) или из загруженного файла Excel. Сейчас это рабочий прототип, его делали в чате claude.ai; дальше развиваем в этом репозитории в Claude Code. Сайт — GitHub Pages, выкладка автоматическая при пуше в `main` (`.github/workflows/pages.yml`).

## Структура папки
- `site/index.html` — **основная сборка** (`python3 tools/build.py --web`): без вшитой таблицы, данные только из Google. Её собирает и выкладывает на GitHub Pages workflow `.github/workflows/pages.yml`; `site/` не коммитим. Вшитый проект «Мероприятие 24–28 ноября» убран по просьбе Ивана (18.11).
- `index.html` — старый вариант сборки с вшитой таблицей (`python3 tools/build.py data/plan.xlsm "…"`), сейчас не используется. Если вшитой таблицы нет (`BUILTIN_SHEETS = null`), список проектов не может опустеть: подключается `LIVE_SHEET`.
- `src/template.html` — то же приложение без данных: вместо них плейсхолдеры `__RAW__` (сырые ячейки листов) и `__NAME__` (название проекта). **Код правим здесь.**
- `tools/build.py` — собирает `index.html` из шаблона и таблицы: `python3 tools/build.py data/plan.xlsm "Мероприятие 24–28 ноября"` (нужен `openpyxl`).
- `data/` — сюда можно положить таблицу для локальной проверки (в git не попадает, см. `.gitignore`).
- `excel/macro-list.vba` — макрос множественного выбора для Excel (копия того, что в таблице).
- `gas/Code.gs`, `gas/appsscript.json` — скрипт-мост на Google Apps Script для онлайн-таблицы (см. ниже).

## Что уже сделано
- Импорт .xlsx/.xlsm в браузере кнопкой «Загрузить таблицу» (SheetJS с cdnjs, лениво). Загруженные таблицы сохраняются как отдельные проекты в localStorage, переключатель в шапке.
- **Онлайн-таблица с Google Диска (16–18.11)** — см. раздел ниже. Работает с реальной таблицей.
- Тёмная тема, mobile-first. Шапка компактная: название проекта + статистика; вкладки + поиск; строка «дни слева / локации справа»; строка исполнителей.
- **Таймлайн (Гант):** непрерывный через полночь; в режиме «Все дни» шкала начинается за 3 ч до первой видимой работы; в режиме дня — 00:00–24:00 с пунктирным обрезом полос. Зум «−/+». Ширина колонки работ меняется ручкой в шапке (запоминается отдельно для телефона и ноутбука, двойной клик — сброс). Кнопка «По локациям» — группировка с цветными закреплёнными заголовками локаций. В колонке слева: название (переносится целиком), значок заметки, если есть комментарий; ниже время `23:00 → 05:00⁺¹`, исполнители, и локация — только при «Все локации» без группировки.
- **Полосы:** цвет исполнителя — `CONTR_COLORS` (как в выпадающем списке Google-таблицы, насыщеннее; серым в Google дал свои разные цвета; кого нет в словаре — `PALETTE` по порядку); если исполнителей несколько — полоса делится по высоте на равные слои; при фильтре по исполнителю его слой первый (верхний). Заезды — цвет исполнителя + белый грузовик внутри полосы, а если полоса узкая — жёлтый грузовик сбоку. ФСО — ярко-красные со свечением. **Моменты** (указано только одно время) — полоса в 1 час, цвет растворяется к неизвестному краю (mask-image), внутри стрелка: «до 22:00» — стрелка приходит к правому краю, «15:00» — выходит от левого края с засечкой (`pointBar`).
- **Список:** по дням; работа через полночь показывается в обоих днях («до 26.11» / «продолжение с 25.11 23:00»). Кнопка «По локациям»: сначала одна локация, внутри по дням, потом другая (заголовки локации и дня закреплены). Цветная черта слева карточки делится на цвета исполнителей (выбранный — сверху). Заезды: обычный белый текст, жёлтый грузовик перед названием, плашка зоны разгрузки прижата вправо. Плашка локации — только при «Все локации» (или нескольких) без группировки: тогда локация справа, а зона разгрузки — отдельной строкой под названием; при группировке или одной локации зона разгрузки справа (`showLocTag`).
- **Заезды:** таблица по дням с фильтром по зоне разгрузки, тип «Заезд/Выезд», кнопки «Копировать для Excel» (TSV) и «Копировать текстом» (для мессенджера). Скачивание файлов в артефакте запрещено, поэтому копирование.
- **Фильтры (десктоп, 18.11):** одна строка `#fBar` — кнопки-выпадашки «Дата / Локация / Исполнитель» (в кнопке видно текущее значение, «MMG +1» при нескольких), «Только заезды», «По локациям», «Сбросить фильтры»; по нажатию ниже раскрывается `#fPanel` со значениями этого фильтра (переносятся на несколько строк), повторное нажатие сворачивает (`fOpen`, не сохраняется). Старые ряды `.frow2/#fContr` на десктопе скрыты, на телефоне — наоборот, там прежняя панель под воронкой.
- **Фильтры:** день, локации (`state.zones`, можно несколько), исполнители (`state.contrs`, можно несколько; пустой список = «все», кнопка «Все…» сбрасывает выбор), «Только заезды», зона разгрузки (во вкладке «Заезды»), поиск только по названию работы (с подсветкой). Кнопка «По локациям» видна, когда выбраны все локации или несколько; при одной локации группировка включена всегда. Выбранные исполнители — верхние слои полосы. Состояние в localStorage (кроме поиска); старые `state.zone/contr` мигрируют.
- **Выделение и карточка:** в таймлайне тап по тексту названия слева (подчёркивается при наведении) или по цветной полосе открывает карточку, тап по остальной строке — выделяет. В списке и заездах первый тап выделяет, повторный открывает карточку. При смене фильтра/вкладки вид прокручивается к выделенной работе, если она осталась в выборке. Карточка: время, длительность, дни, локация, зона разгрузки, исполнители, номер строки Excel, комментарий; на ноутбуке широкая (760px).
- **Замечания к таблице** (оранжевая кнопка): конфликт даты и разделителя, пустые поля, значения не из листа «Списки» (опечатки/старые названия).

## Онлайн-таблица с Google Диска
Оригинал монтажного плана лежит на Google Диске рук-про, все правят его онлайн в Google Таблицах (это .xlsx в режиме Office, ~590 КБ). Приложение не загружает файл, а читает его через **скрипт-мост**:
- `gas/Code.gs` — веб-приложение Google Apps Script. Иван развернул его **под своим личным Google-аккаунтом** (не служебным), поэтому `ALLOWED` ограничен ID таблицы ЛУКОЙЛ, а `appsscript.json` даёт скрипту только `drive.readonly` + `script.external_request`. Развёртывание: «Выполнять от имени: я», «Доступ: Все». После правки кода — «Управление развёртываниями» → новая версия (адрес `/exec` не меняется).
- Запрос `…/exec?id=<ID файла>&since=<modified>` → если не менялось `{unchanged:true}`, иначе `{modified, name, data: base64 .xlsx}`. Работает и для нативной Google Таблицы (экспорт в xlsx), и для .xlsx/.xlsm в режиме Office. Время изменения кэшируется на 10 с.
- Мост: `https://script.google.com/macros/s/AKfycbyVt--frIaYp_q65NQnTP02aULm6RgUnekNfpnPM4-W5N8LD5tAinhcmrNV0DUlHhnb/exec`. Таблица ЛУКОЙЛ 35: ID `11SofZ2n57scQpGyay51Vsle1KVxrkB3M`. Оба вшиты в шаблон константами `LIVE_API` и `LIVE_SHEET` (в начале скрипта, сразу после `store`): при первом открытии таблица подключается сама (флаг `mp.auto.<ID>`), дальше уважается выбор проекта пользователем.
- В приложении: в списке проектов «＋ Подключить монтажный план Online (Google Таблицы)…» → ссылка на таблицу + адрес моста (`mp.api` в localStorage переопределяет `LIVE_API`). Онлайн-проект: `{id:"g"+fileId, live:{file}, sheets, modified}`, последняя версия кэшируется в localStorage (работает без сети, статус «нет связи»).
- Опрос каждые `POLL_MS` = 15 с, только когда вкладка видна; при возврате в приложение — сразу. При изменении — тост «Таблица обновилась», фильтры и выделенная работа сохраняются (работа ищется по действию+началу).
- Кнопка «Синхронизировать» в шапке (только у онлайн-проекта): забирает таблицу целиком сейчас, не дожидаясь опроса (`forceSync`).
- Статус в шапке перед статистикой: зелёная точка «онлайн · изм. 19:22» / оранжевая «нет связи» (причина — в подсказке).
- Ссылка на проект: пункт «🔗 Скопировать ссылку на проект» → `?sheet=<ID>[&api=<мост>][&contr=<исполнитель>]` (если выбран исполнитель — ссылка откроется сразу на нём). Ссылка с `?sheet=` автоматически добавляет и открывает проект.
- **Пароль к проекту (19.11).** Проверяет мост, а не приложение (код сайта публичный, проверка в браузере ничего бы не защитила). Пароль хранится в «Свойствах скрипта» Apps Script: `PASS_<ID таблицы>` или общий `PASS`, в коде и в репозитории его нет. Нет свойства — таблица без пароля. Мост отвечает `{error, auth:"need"|"wrong"}`; блокировки после неверных попыток нет (отключили 19.11 по просьбе Ивана). Приложение передаёт `&key=`, хранит пароли в `mp.pass` (по ID файла), при `auth` стирает кэш таблицы и открывает окно пароля (`openPass`/`submitPass`, само — один раз за сеанс, иначе пункт меню «🔑 Ввести пароль проекта…» — он виден только пока проект ждёт пароль). В ссылку на проект пароль не попадает.
- Ограничение: подрядчики открывают сайт на GitHub Pages. В артефакте claude.ai запросы к script.google.com, скорее всего, заблокированы.
- Из песочницы Claude Google недоступен: проверка — моком моста (Playwright перехватывает script.google.com) и файлом, который Иван скачал из Google.

## Формат таблицы
Общее для обеих версий:
- Лист с планом ищется по заголовкам в первых 15 строках, берётся **первый подходящий лист** по порядку вкладок. В Google-файле несколько версий листов: «Монтажный план 35 лет v3» (первый, актуальный), v2, v1, «…30 лет OLD» — если рук-про переставит вкладки, приложение возьмёт другую версию.
- Заголовки: Время начала, Время окончания, Действие, **Локация** (раньше «Зона», «Место»), **Зона разгрузки** (раньше «Зона заезда», «Ворота»), **Исполнитель** (раньше «Подрядчик»), Комментарии; «Дата» — необязательна. Старые названия тоже распознаются. Зона разгрузки проверяется раньше локации, чтобы «Зона …» не путалась. Колонки «Хелперы» и «Ответственный» игнорируются (берётся первая колонка исполнителя).
- Строки-разделители дней: текст «24 ноября» без времени — в любой колонке, в том числе в «Действие» (так в Google-версии, где колонки «Дата» нет). Если «Дата» и разделитель расходятся — берём разделитель и пишем замечание. Год — из колонки «Дата», иначе текущий.
- Время — значение времени или текст «23:00»/«12.00». Окончание ≤ начала → работа заканчивается на следующий день.
- **Только одно время** → момент (`it.point`): только окончание — «до 22:00» (срок), только начало — «15:00». Хранится как start = end − 1 мин, в Ганте — растворяющаяся полоса со стрелкой, во всех подписях через `span(it)`.
- Локация и Исполнитель — несколько значений через ` / ` (макрос Excel) или `, ` (выпадающий список Google с несколькими значениями).
- Значения, начинающиеся с «Все»/«ВСЕ» («Все локации/зоны», «ВСЕ СЛУЖБЫ»), попадают в каждый фильтр.
- Строки исполнителя «ФСО» (режимные мероприятия) видны в фильтре любого исполнителя и выделены красным (`ALERT_RE` в коде).
- Зона разгрузки заполнена только у заездов/выездов — это и есть признак заезда. «Выезд/Вывоз/Погрузка/Отъезд…» в начале действия или «за кофрами» в любом месте (машина приезжает забрать кофры) → тип «выезд».
- Зоны разгрузки рисуются цветными плашками `GATE_COLORS` (фон/текст как в выпадающем списке Google; в тёмной теме фон приглушён) — в списке, во вкладке «Заезды» (и кнопки фильтра) и в карточке. Новая зона без цвета — прежняя жёлтая плашка; цвет добавить в `GATE_COLORS`.
- Справочники: лист «Списки» (старый Excel) и/или выпадающие списки (data validation) — задают порядок кнопок, цвета по порядку и проверку опечаток. Выпадающие списки SheetJS не читает: `xlsxLists()` сам распаковывает .xlsx (DecompressionStream) и вытаскивает `<dataValidation type="list">`, результат хранится в `proj.lists`.

## Работы через полночь
Пользователь вручную дублирует такие работы: 25.11 23:00–05:00 и 26.11 00:00–05:00. Приложение склеивает дубль (то же действие + локация, начало 00:00 следующего дня, тот же конец) в одну работу. В фильтре дня работа видна в обоих днях. Если дубля нет — показывается в обоих днях автоматически.

## Мобильная версия (≤700px) — зафиксирована 15.11
Десктоп зафиксирован раньше, мобильные правки делаем только в media-query `max-width:700px`.
- Вкладки только «Таймлайн» и «Список» (вкладки «Заезды» на телефоне нет).
- Фильтры скрыты по умолчанию, открываются кнопкой-воронкой справа от поиска; синяя точка на воронке — если выбран день/локация/исполнитель/«только заезды».
- В панели фильтров: строка дней; строка локаций (первыми идут иконка-кнопка «Только заезды» (грузовик) и иконка-кнопка группировки «По локациям»); строка исполнителей.
- Шапка с названием и панель вкладок лежат поверх контента (position:absolute) и сдвигаются transform'ом вслед за пальцем: вниз по списку — уезжает, вверх — возвращается только у самого начала списка. Отпустил на середине — доводка (прячется до конца или список докручивается до верха). Закреплённые заголовки держатся под шапкой через CSS-переменную `--ovl` (= −off), у `.view` padding-top = `--ovlMax`.
- Кнопки зума «−/+» слева в ячейке «Работа», подальше от ручки ширины колонки.
- Подпись даты над шкалой закрепляется при горизонтальной прокрутке (исправлено и на десктопе).
